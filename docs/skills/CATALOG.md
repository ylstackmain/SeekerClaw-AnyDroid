# SeekerClaw Skill Catalog

This catalog provides a directory of built-in skills available in SeekerClaw.

## General Skills

- **bookmark**: Save and organize URLs for later retrieval.
- **briefing**: Get a daily summary of your notifications, news, and tasks.
- **calculator**: Perform mathematical calculations.
- **crypto-prices**: Check real-time prices for cryptocurrencies.
- **define**: Look up word definitions and synonyms.
- **github**: Interact with GitHub repositories, issues, and PRs.
- **joke**: Get a random joke.
- **movie-tv**: Search for information about movies and TV shows.
- **netwatch**: Monitor website status and availability.
- **news**: Fetch latest news from various sources.
- **notes**: Create and manage personal notes.
- **quote**: Get an inspirational quote.
- **reminders**: Set and manage reminders.
- **summarize**: Summarize long text or articles.
- **timer**: Set and manage countdown timers.
- **todo**: Manage your todo lists.
- **translate**: Translate text between different languages.
- **weather**: Get real-time weather information and forecasts.

## Research Skills

- **research**: General research tool for finding information on the web.
- **web-search-pro**: Advanced multi-source research and synthesis using `web_search` and `web_fetch`.

## System Skills

- **calclaw**: Calendar integration for managing events.

---

*Note: The availability of some skills may depend on the search provider or API keys configured in the app settings.*
